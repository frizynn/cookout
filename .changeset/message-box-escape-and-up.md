In the web UI, ↑ in an empty message box (or a thread's reply box) moves to the newest message; with text in the box it moves the cursor as before. Escape in the box leaves it, keeping what you typed, and puts focus back where you were: the message or control focused before the box, or else the newest message. The reaction keys `+` and `-` on a focused message now sit in the keyboard shortcut list under "Message", and the message menu's React with 👍 and React with 👎 show them.
