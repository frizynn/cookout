In the web UI, pressing a control that goes away keeps focus on a named element instead of the page: removing a file to send focuses the next file's Remove, or the message box once none is left; calling a command or cancelling its form, and saving a scheduled message, focus the message box; the schedule dialog's Cancel focuses Post later; Close thread and Reopen thread focus the button that replaces them; and a thread's Close panel link focuses the thread's message in the channel.
