In the web app, ← on a channel message moves focus to the sidebar, on that channel's link, and → on a sidebar channel link moves into its messages, on the selected or newest one (opening the channel if it isn't open). ↓ on the newest message moves into that column's message box. Ctrl+] and Ctrl+[ now move only between the three columns (the sidebar, the messages and the thread panel): the message box is no longer a stop, and they still work from inside it. Inside a text box ← and → only move the cursor.
