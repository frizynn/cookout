In the web app, each Escape goes out one level: a menu, card or the search box closes first, then a text box is left with its draft kept (or a prompt form is cancelled), then the thread or profile panel closes with focus back on what opened it, and last the shown channel is marked read, announcing "#channel marked read". In the Inbox, Escape with nothing left to close marks the selected row read, as e does. Ctrl+] and Ctrl+[ (Control on a Mac too) move focus between the sidebar, the messages, the side panel and the message box, each returning focus where it was left, and work from inside text boxes.
