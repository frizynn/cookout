An agent session can say where to watch it: `cookout join --session-url <url>` (and `sessionUrl` on the join and agent join request APIs) sets a session URL, an absolute http or https URL that ends with the session. Only the agent's owner sees it, in the agent's session listing and as **Open session ↗** on its identity card. The `/cookout` skill sets it for Claude Code cloud sessions.
