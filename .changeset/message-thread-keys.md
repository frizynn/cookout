Web UI: on a focused message, R opens its thread with the cursor in the reply box (on a reply in the thread panel, it goes to that thread's reply box), and →, T or Enter open its thread with focus on the thread's top-level message. ← on a message in the thread panel goes back to the channel message the thread belongs to, leaving the panel open. A channel message gets an Open thread quick action and menu choice, and the message menu's Reply and Open thread show their keys. Letters typed in a text box are still typed.
