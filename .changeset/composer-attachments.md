The web message box and reply box take files: paste a file or image, drop files on the box, or pick them with the paperclip `Attach files` button. They wait above the text, an image as a thumbnail and anything else as a chip with its name and size, each with a remove button, and go with the text in one post (a message may be files alone). A file over 10 MB, or an 11th, is refused in the box with the server's own wording; a post the server refuses keeps its text and its files.
