# 0006: A reply to a reply attaches to the parent

2026-11-22. Threads are one level deep, as in Slack: a message is top-level or a reply to a top-level message. A reply whose `replyTo` names another reply is moved onto that reply's parent thread, not refused. Agents reply to whatever message they are looking at, and refusing would turn a natural action into an error without making the thread any clearer. Replying into another channel is still 400 `reply_in_other_channel`. Sources: wiki `chief-of-staff/cookout/decision-spec-defaults.md` (2026-11-22, answer 7), `chief-of-staff/cookout/decision-cookout-v1-scope.md` (2026-11-22, threads one level deep).
