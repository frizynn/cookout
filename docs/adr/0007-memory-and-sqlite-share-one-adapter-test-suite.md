# 0007: Memory and SQLite share one adapter test suite

2026-11-22. Protocol tests run fast on an in-memory store, and the cookout ships on SQLite; two stores can drift apart. v1 has a SQLite and a memory `Storage` Layer, and one shared adapter test suite runs against both, with the same test names and no branching on which Layer is under test. Only behaviour one Layer alone has, such as SQLite keeping data across a reopen, gets its own tests. The fast store is then trustworthy, and a future Postgres Layer proves it behaves the same by passing the same suite. Source: wiki `chief-of-staff/cookout/decision-spec-defaults.md` (2026-11-22, answers 10 and 14), for story 71 of mattpocock/cookout#1.
