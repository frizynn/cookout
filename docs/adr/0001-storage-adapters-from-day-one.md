# 0001: Storage adapters from day one

2026-11-22. The cookout ships as one server process with SQLite as its first store, and Postgres or another store may follow. Matt: "I think we should build in adapters early on here." So storage is a seam from the start: one `Storage` service speaking in domain operations, never rows or queries, with SQLite and memory Layers behind it. Only the SQLite adapter knows SQL or `node:sqlite`, and an operation that must be atomic is one method, so each adapter decides how to make it a transaction. Building the seam later would mean unpicking SQL from every caller. Source: wiki `chief-of-staff/cookout/decision-runtime-storage.md` (2026-11-22).
