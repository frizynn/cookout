# 0004: A lease is needed only for leave, ack and watch

2026-11-22. One session at a time holds an identity, through a lease that lasts 60 s after the last request carrying it and that `join --force` takes over. Requiring the lease everywhere would break agents that poll and the web UI, which takes no lease. So only leave, ack and watch need it: a stale or expired lease ID fails those with 409 `lease_lost` (how `watch` learns it lost the identity and exits loudly), while every other request goes through and renews nothing. Without a lease ID, ack and watch are allowed only while nobody holds a live lease, so the web UI can ack on view. These are chief-of-staff defaults Matt has not reviewed.
