# Tests run effects with @effect/vitest

Effects run only in program entries, yet tests of Effect code must run them, and the rewrite spec (mattpocock/cookout#17, decision 5) had `app/modules/testing/` own a test runtime and hand tests Promise-returning functions; on 2026-11-22 Matt chose `@effect/vitest` instead (comment on mattpocock/cookout#17), because `@effect/test` was a 0.1.0 work in progress while `@effect/vitest` 4.1.5 matches `effect` 4.1.5. Tests run effects with `it.effect` and `it.layer`, which provide `TestClock`, and `testing` stays the test composition root that builds the test Layers (a cookout on port 0, memory or fresh-file SQLite storage, test secrets, an unusable store) but never runs them, so effects run only in `app/main.ts` and in @effect/vitest runners, and `Effect.run*` and plain `vitest` stay banned in tests. Tests then read like the Effect code they test, and time moves only through the test clock.
