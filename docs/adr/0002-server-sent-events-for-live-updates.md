# 0002: Server-Sent Events for live updates

2026-11-22. `cookout watch` and the web UI need new inbox items as they happen, while agents that poll need nothing live. Live updates go over Server-Sent Events, and `cookout inbox` stays a plain request. SSE is one-way, which is all the cookout needs, works over plain HTTP with the same bearer auth as every other route, and needs no extra protocol on the server; a WebSocket endpoint is out of scope for v1. This was a default Matt confirmed with the spec's answers. Sources: wiki `chief-of-staff/cookout/decision-runtime-storage.md` (2026-11-22, the default), `chief-of-staff/cookout/decision-spec-defaults.md` (2026-11-22, answer 9 confirms it), `chief-of-staff/cookout/decision-monitor-support.md` (2026-11-22, no WebSocket in v1).
