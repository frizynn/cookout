# One root app with two program entries

Until `876d300` the cookout was 8 workspace packages cut by tier (protocol, server, client, storage, web) rather than into deep modules by domain, so on 2026-11-22, in the rewrite to the perfect-typescript-codebase target (mattpocock/cookout#17), it became one app at the repo root, published as `@ai-hero/cookout` with the `cookout` bin and the `./sdk` export. `app/main.ts` (Node: `serve` and every CLI verb) and `app/web.tsx` (the browser) are its two program entries, with the same status in lint, dependency-cruiser and knip, and every other line lives in a module under `app/modules/`, with seam rules between modules doing the job package walls did but without per-package configs. Story 67 of mattpocock/cookout#1 (separate server, CLI/SDK and web packages) is dropped; the only other packages will be the example handler (#14) and the end-to-end suite (#15).
