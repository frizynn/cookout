# 0008: One root app with two program entries

2026-11-22. Until `876d300` the cookout was 8 workspace packages cut by tier (protocol, server, client, storage, web), which is not a cut into deep modules by domain. It is now one app at the repo root, published as `@ai-hero/cookout` with the `cookout` bin and the `./sdk` export. `app/main.ts` (Node: `serve` and every CLI verb) and `app/web.tsx` (the browser) are its two program entries, with the same status in lint, dependency-cruiser and knip; every other line lives in a module under `app/modules/`. Seam rules between modules do the job package walls did, without per-package configs. Story 67 of mattpocock/cookout#1 (separate packages) is dropped; the only other packages will be `packages/handler-example` (#14) and `packages/e2e` (#15).
