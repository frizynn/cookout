# 0009: Plain-TS wire types with generated validators

2026-11-22. The backend is Effect, but the SDK and the web must stay plain TypeScript and still validate what the server sends, since the server is outside input to them. Each module's `index.ts` holds plain-TS wire types and brands; each backend `Schema` is type-checked against its wire type (`matchesWire`), so the two can't drift. A script turns the response Schemas into JSON Schema and then into standalone ajv validators, committed under the SDK, and `pnpm check` fails when they are stale. The SDK decodes every response with them and fails with `bad_response` on a mismatch. One definition serves all three sides, and no Effect reaches the published SDK. Source: wiki `chief-of-staff/cookout/decision-perfect-ts-rewrite.md` (2026-11-22, answer 2); mattpocock/cookout#17, decisions 7 and 8.
