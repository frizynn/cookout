# The lint opt-out list lives outside the ADRs

2026-11-23 (mattpocock/cookout#129). Supersedes the part of [ADR 0012](0012-lint-opt-outs.md) that keeps the list of lint opt-outs in the ADR itself. ADRs are dated history and are never rewritten, but tickets amended ADR 0012 each time they turned a rule off or loosened one, so it had become a living allowlist. The list, each entry with its reason, now lives in [docs/lint-opt-outs.md](../lint-opt-outs.md), and a commit that turns a rule off or loosens it adds its entry there. ADR 0012's rule stands: a rule is off or loosened only for a contradiction, and a rule that is only harsh stays on. An opt-out that is itself a real trade-off can still get its own ADR, which the list links to. `scripts/check-docs.ts` checks that file's links but not its code spans, because those name lint rules such as `import/no-default-export`, which look like paths.
